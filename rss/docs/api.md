# 클라이언트-서버 API

상세: [api.ai.md](api.ai.md)

웹앱과 nvim이 서버에 요청할 수 있는 것들입니다. 모든 요청에는 토큰이 필요합니다.

| 영역 | 할 수 있는 것 |
|------|------|
| 피드 | 목록을 보고, 추가하고, 삭제하고, 바로 새로고침할 수 있습니다. |
| 글 | 피드별·안 읽은 글·즐겨찾기로 목록을 보고, 본문을 보고, 읽음·즐겨찾기를 바꾸고, 모두 읽음 처리할 수 있습니다. |
| 안 읽은 글 수 | 피드별 개수와 전체 개수를 볼 수 있습니다. |
| OPML | 내보내고 가져올 수 있습니다. |

- 글 목록은 한 번에 일부만 주고, "다음 페이지" 표시를 함께 줍니다.
- API 주소에 버전(v1)이 붙어 있어서, 나중에 API를 바꿔도 기존 클라이언트가 깨지지 않습니다.
