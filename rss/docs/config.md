# 설정

상세: [config.ai.md](config.ai.md)

설정값은 코드에 박지 않고, 이 문서에 정리한 항목으로만 바꿉니다.

| 구성 | 무엇을 설정하나 | 어디서 |
|------|------|------|
| 서버 | 주소·포트, DB 파일 위치, 토큰, 갱신 주기, 피드를 받을 때의 시간·크기 제한, 한 번에 주는 글 수, 요청 크기·시간 제한을 설정합니다. | 환경 변수로 받습니다. |
| 웹앱 | 토큰을 설정합니다. 서버 주소는 기본으로 같은 곳을 씁니다. | 앱의 설정 화면에서 받습니다. |
| nvim | 서버 주소, 토큰, 키 배치를 설정합니다. | `setup{}` 또는 환경 변수로 받습니다. |

- 서버는 일단 이 Mac에서 실행합니다. 폰에서는 Tailscale로 접속합니다. 클라우드로 옮길 때도 설정만 바꾸면 되도록 합니다.
- 토큰은 문서나 코드에 쓰지 않습니다.
