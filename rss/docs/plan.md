# RSS 리더 만들기

상세: [plan.ai.md](plan.ai.md)

## 왜
Folo를 참고하려고 분석했지만, 공개된 것은 앱뿐이고 서버는 비공개였습니다. 그래서 서버를 직접 두고, 거기에 붙는 웹앱과 nvim 플러그인을 만듭니다.

## 구성
| 구성 | 기술 | 문서 |
|------|------|------|
| 서버 | Go + SQLite | [server.md](server.md) |
| 웹앱 (Windows, Android, iOS) | TypeScript PWA(Progressive Web App) | [app.md](app.md) |
| nvim 플러그인 | Lua | [nvim.md](nvim.md) |
| 클라이언트-서버 API | – | [api.md](api.md) |
| 설정 | – | [config.md](config.md) |

- 기능은 피드 구독/삭제, 글 목록, 본문 보기, 읽음/즐겨찾기, 안 읽은 글 수, OPML 가져오기/내보내기입니다.
- Folo 코드는 복사하지 않습니다. 라이선스(AGPL) 문제를 피하려고 구조만 참고합니다.

## 확장성 결정
| 주제 | 결정 |
|------|------|
| 사용자 | 완전한 단일 사용자로 갑니다. 여러 사용자를 지원하려면 나중에 다시 설계합니다. |
| 저장소 | 인터페이스 뒤에 SQLite를 둡니다. 다른 DB로 바꿀 수 있습니다. |
| 본문 HTML | 서버가 저장할 때 안전하게 정리합니다. 웹앱과 nvim은 정리된 HTML을 그대로 씁니다. |
| 서버 구조 | 레이어별로 패키지를 나누고, API 경로에 버전(v1)을 붙입니다. |
| 앱 | Vue로 만든 TypeScript 웹앱(PWA) 하나이며, MVVM 구조입니다. Go 서버가 함께 띄웁니다. |
| 서버 위치 | 일단 이 Mac에 둡니다. 폰은 Tailscale로 접속합니다. 클라우드는 나중에 검토합니다. |

## 하지 않는 것
AI 요약, RSSHub, 본문 자동 추출, 여러 사용자, 푸시 알림, 앱 오프라인 모드는 이번 범위에서 제외합니다.

## 순서
1. 서버를 만듭니다.
2. nvim 플러그인을 만듭니다. 가장 작아서 서버를 검증하기 좋습니다.
3. 웹앱을 만듭니다.
4. 실행법을 정리합니다.

## 위험
- 서버가 이 Mac에 있으므로, Mac이 꺼지거나 잠들면 웹앱과 nvim을 쓸 수 없습니다.
