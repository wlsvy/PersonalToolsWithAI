# 서버

상세: [server.ai.md](server.ai.md)

- 등록한 피드를 주기적으로 가져와 글을 저장합니다. 바뀐 것이 없으면 다시 받지 않습니다.
- 본문 HTML은 저장하기 전에 위험한 부분(스크립트 등)을 걸러냅니다. 글 링크도 http/https만 남깁니다.
- 기본적으로 내부망 주소의 피드는 가져오지 않습니다. 로컬에서 띄운 피드를 쓰려면 설정으로 허용합니다.
- 웹앱과 nvim에는 버전이 붙은 API(v1)로 데이터를 줍니다. 접속하려면 토큰이 필요합니다.
- 저장소는 SQLite이지만 교체할 수 있도록 경계를 둡니다.
- 설정은 코드가 아니라 환경 변수로 받습니다. 항목은 [config.md](config.md)에 있습니다.
- 웹앱 파일도 이 서버가 함께 띄웁니다.
- 실행 파일 하나로 배포합니다.
