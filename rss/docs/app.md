# 앱 (웹앱)

상세: [app.ai.md](app.ai.md)

- TypeScript 웹앱(PWA) 하나로 Windows, Android, iOS를 지원합니다. 브라우저에서 열거나 홈 화면에 설치해 씁니다.
- 추가 개발 도구(Xcode, Android SDK)가 필요 없습니다.
- UI는 Vue로 만들고, 구조는 MVVM으로 갑니다. 화면과 상태·로직을 분리합니다.
- 화면은 설정(토큰), 피드 목록, 글 목록, 본문 네 가지입니다.
- 본문을 열면 읽음 처리합니다. 즐겨찾기와 원문 열기를 지원합니다.
- 웹앱은 Go 서버가 직접 띄웁니다. 서버 하나만 실행하면 됩니다.
- 폰에서는 Tailscale로 접속합니다. HTTPS가 자동으로 붙어서 홈 화면 설치가 되고, 집 밖에서도 쓸 수 있습니다. 공유기 포트를 열 필요가 없습니다.
- 나중에 스토어 앱이 필요하면 같은 코드를 앱으로 감쌉니다.
