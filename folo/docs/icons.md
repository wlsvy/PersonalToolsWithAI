# 피드 아이콘

상세: [icons.ai.md](icons.ai.md)

## 목적과 배경

목록에서 글이 어느 사이트에서 왔는지 한눈에 알아보도록 각 줄 앞에 사이트별 아이콘을 붙입니다. 터미널은 실제 파비콘 이미지를 그릴 수 없으므로 도메인을 아이콘으로 바꾸는 표를 씁니다.

처음에는 폰트 설치가 필요 없는 이모지를 썼습니다. 사용자 요청으로 Nerd Font 글리프로 교체합니다. 사이트 로고를 직접 표시할 수 있고, 글리프는 한 칸 폭이라 이모지보다 줄 정렬이 안정적입니다.

## 결정 사항

- 사이트 아이콘의 기본값을 Nerd Font 글리프로 바꿉니다. 대응하는 로고가 없는 사이트는 의미가 비슷한 글리프를 씁니다.
- 별표 표시도 같은 글리프 계열로 바꿉니다. 별표는 설정으로 빼지 않습니다. 사용하는 PC에 모두 폰트를 설치했고, 폰트가 없으면 깨져 보여도 괜찮다고 사용자가 정했기 때문입니다.
- 이모지 모드와 글리프 모드를 나누는 옵션은 두지 않습니다. 사이트 아이콘은 설정에서 값을 덮어쓰면 이모지도 그대로 쓸 수 있습니다.
- 플러그인에 널리 쓰는 사이트의 기본 표를 두고, 사용자는 설정에서 항목을 추가하거나 덮어쓸 수 있습니다. 표에는 Nerd Font에 로고가 있는 사이트만 더 넣습니다. 특정 사용자의 구독 사이트를 플러그인 기본값에 넣지 않기 위해서입니다.
- 표에 없는 사이트는 도메인에서 딴 두 글자 배지로 표시합니다. 예를 들어 `openai.com`은 `OP`, `science.nasa.gov`는 `NA`입니다. 전처럼 모두 같은 아이콘으로 보이면 구분이 안 되기 때문입니다.
- 주소가 없거나 도메인을 알 수 없는 글만 기본 RSS 아이콘을 씁니다.
- 글리프는 한 칸, 배지는 두 칸이므로 아이콘 자리를 두 칸으로 고정해 줄을 맞춥니다.
- 아이콘에 사이트별 색상을 입힙니다. 대표색이 뚜렷한 사이트는 그 색을 쓰고, 나머지는 도메인으로 팔레트의 색 하나를 고릅니다. 같은 사이트는 늘 같은 색입니다.
- 색상과 팔레트는 설정에서 바꿀 수 있습니다.
- 사이트는 피드의 홈페이지 주소로 판단하고, 그 주소가 없으면 글 주소로 판단합니다.
- 하위 도메인은 상위 도메인의 아이콘을 물려받습니다. 예를 들어 `blog.github.com`은 `github.com`의 아이콘을 씁니다.

## 범위

- 하는 것: 목록 각 줄의 아이콘과 색상 표시, 두 글자 배지, 설정으로 표 추가·덮어쓰기·특정 항목 끄기·기능 전체 끄기를 지원합니다.
- 하지 않는 것: 파비콘 이미지 다운로드와 표시, 미리보기 창 제목의 아이콘, 피드 이름 기준 매칭입니다.

## 순서

1. CLI 계층이 피드 홈페이지 주소를 함께 넘기도록 합니다.
2. 도메인을 아이콘으로 바꾸는 함수와 기본 표를 만듭니다.
3. 목록 줄에 아이콘을 붙입니다.
4. 가짜 CLI 테스트에 아이콘 점검을 추가합니다.
5. 기본 아이콘과 별표를 Nerd Font 글리프로 바꿉니다.
6. 도움말, 테스트, 관련 문서를 맞춥니다.
7. 기본 표를 넓히고 두 글자 배지를 추가합니다.
8. 아이콘 자리를 두 칸으로 고정하고 색상을 입힙니다.

## 남은 위험

- Nerd Font가 없는 터미널에서는 아이콘이 빈칸이나 깨진 문자로 보입니다. 사용자가 받아들인 동작입니다. 별표는 설정으로 바꿀 수 없습니다.
- 글리프가 실제로 올바르게 보이는지는 터미널에서 눈으로 확인해야 합니다. 자동 테스트는 값만 검증합니다.
- 일부 로고는 Nerd Fonts v3에만 같은 자리에 있습니다. 구버전 폰트에서는 다른 모양으로 보일 수 있습니다.
- 배지는 공개 도메인 목록 없이 간단한 규칙으로 만듭니다. `a16z.simplecast.com`처럼 공용 호스팅에 있는 사이트는 호스팅 이름(`SI`)으로 나오고, 첫 두 글자가 같은 사이트는 배지가 겹칩니다. 색상으로 어느 정도 구분되고, 필요하면 설정에서 직접 지정합니다.
- 팔레트 색이 일부 테마에서 흐리게 보일 수 있습니다. 24비트 색상을 끈 터미널에서는 색 없이 표시됩니다.
- 타임라인 응답에 피드 홈페이지 주소가 실제로 들어 있는지는 확인하지 못했습니다. SDK 타입에는 있습니다. 없으면 글 주소로 판단하므로 동작에는 지장이 없습니다.

## 확장성 결정

사용자가 다음을 확정했습니다.

1. 매핑 위치: 플러그인 기본 표에 설정 덮어쓰기를 더합니다.
2. 아이콘 종류: 이모지에서 Nerd Font 글리프로 바꿉니다(2026-11-08).
3. 교체 범위: 사이트 아이콘과 별표를 모두 바꿉니다.
4. 별표 설정: 두지 않습니다.
5. 표에 없는 사이트: 두 글자 배지와 색상으로 표시합니다(2026-11-08). 이미지 표시는 하지 않습니다.
