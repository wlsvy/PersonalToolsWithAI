# 피드 아이콘

상세: [icons.ai.md](icons.ai.md)

## 목적과 배경

목록에서 글이 어느 사이트에서 왔는지 한눈에 알아보도록 각 줄 앞에 사이트별 이모지를 붙입니다. 터미널은 실제 파비콘 이미지를 그릴 수 없으므로 도메인을 이모지로 바꾸는 표를 씁니다.

## 결정 사항

- 아이콘은 이모지를 씁니다. 폰트 설치가 필요 없기 때문입니다.
- 플러그인에 흔한 사이트 몇 개의 기본 표를 두고, 사용자는 설정에서 항목을 추가하거나 덮어쓸 수 있습니다.
- 표에 없는 사이트는 기본 아이콘 하나를 씁니다.
- 사이트는 피드의 홈페이지 주소로 판단하고, 그 주소가 없으면 글 주소로 판단합니다.
- 하위 도메인은 상위 도메인의 아이콘을 물려받습니다. 예를 들어 `blog.github.com`은 `github.com`의 아이콘을 씁니다.

## 범위

- 하는 것: 목록 각 줄의 아이콘 표시, 설정으로 표 추가·덮어쓰기·특정 항목 끄기·기능 전체 끄기를 지원합니다.
- 하지 않는 것: 파비콘 이미지 다운로드와 표시, 미리보기 창 제목의 아이콘, 피드 이름 기준 매칭입니다.

## 순서

1. CLI 계층이 피드 홈페이지 주소를 함께 넘기도록 합니다.
2. 도메인을 아이콘으로 바꾸는 함수와 기본 표를 만듭니다.
3. 목록 줄에 아이콘을 붙입니다.
4. 가짜 CLI 테스트에 아이콘 점검을 추가합니다.

## 남은 위험

- 이모지는 터미널마다 표시 폭이 달라 줄 정렬이 어긋날 수 있습니다.
- 타임라인 응답에 피드 홈페이지 주소가 실제로 들어 있는지는 확인하지 못했습니다. SDK 타입에는 있습니다. 없으면 글 주소로 판단하므로 동작에는 지장이 없습니다.

## 확장성 결정

사용자가 다음을 확정했습니다.

1. 매핑 위치: 플러그인 기본 표에 설정 덮어쓰기를 더합니다.
2. 아이콘 종류: 이모지를 씁니다.
