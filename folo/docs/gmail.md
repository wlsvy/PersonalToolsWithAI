# Gmail 섹션

상세: [gmail.ai.md](gmail.ai.md)

## 목적과 배경

메일함을 확인하려고 브라우저로 넘어가지 않고, Folo 대시보드에서 안 읽은 메일을 함께 봅니다. Google 직원들이 만든 `gws` CLI의 `+triage`가 안 읽은 메일의 보낸 사람, 제목, 날짜를 한 번에 돌려주므로 이것을 그대로 씁니다.

## 결정 사항

- 데이터는 `gws`에서 가져옵니다. 플러그인은 토큰을 다루지 않고, 인증은 `gws auth login`이 관리합니다.
- 범위는 보기만입니다. 대시보드에 `Mail` 섹션을 두고 안 읽은 개수와 최근 메일을 보여 줍니다. `<CR>`을 누르면 본문을 미리보기에 띄우고, `gx`를 누르면 브라우저의 Gmail에서 엽니다(2단계에서 바뀌었습니다).
- 메일함을 바꾸지 않습니다. `+triage`는 읽기 전용이라 읽음 처리, 보관, 답장은 하지 않습니다.
- `folo` 플러그인 안에 바로 넣습니다. Folo CLI 코드와 섞이지 않도록 `gws` 호출은 별도 모듈에 둡니다.
- Gmail을 불러오지 못해도 RSS 부분은 정상적으로 보입니다. Mail 섹션에만 오류 한 줄을 표시합니다.

## 범위

- 하는 것: `gws` 호출 모듈, 대시보드 `Mail` 섹션, `<CR>`로 브라우저 열기, `r` 새로고침 시 함께 갱신, 가짜 `gws` 테스트, README 설정 안내입니다.
- 하지 않는 것: 읽음·보관·별표 처리, 답장과 작성, 캘린더, 여러 계정, 자동 새로고침입니다.

## 순서

1. 사용자가 `gws auth setup`과 `gws auth login`을 마칩니다. 실제 `+triage` 출력 형식을 확인했습니다.
2. `gws` 호출 모듈과 가짜 `gws` 스크립트를 만듭니다.
3. 대시보드에 `Mail` 섹션과 `<CR>` 동작을 넣습니다.
4. README, 설정 문서, 진행 내역을 고칩니다.

## 확장성 결정

1. **켜는 방식**: 설정에서 켜야만 보입니다. 기본으로 켜면 `gws`가 없는 환경에서 오류 줄이 보이기 때문입니다.
2. **섹션 위치**: `Mail`은 RSS 위에 둡니다. 메일은 보통 몇 줄이라 아래에 두면 긴 RSS 목록에 밀려 보이지 않습니다.
3. **브라우저 주소의 계정 번호**: Gmail 주소의 `u/0`은 브라우저에서 첫 번째로 로그인한 계정을 뜻합니다. 계정이 여러 개일 때 바꿀 수 있도록 주소 형식을 설정값으로 둡니다.

## 남은 위험

- `gws`는 Google 공식 지원 제품이 아니고 v1.0 전입니다. 업데이트 후 출력 형식이 바뀌면 섹션이 깨질 수 있습니다. 지금 설치된 0.17.0 기준으로 테스트를 고정합니다.
- 인증하려면 Google Cloud 프로젝트와 OAuth 클라이언트를 만들어야 합니다. 이 과정은 사용자가 직접 해야 합니다.
- 개수 배지는 Gmail이 돌려주는 추정치입니다. 정확한 안 읽은 개수와 조금 다를 수 있습니다.

## 2단계: 본문 보기

### 결정 사항

- 메일 줄에서 `<CR>`을 누르면 목록 화면과 같은 오른쪽 미리보기 창에 본문을 띄웁니다. 브라우저로 여는 동작은 `gx`로 옮깁니다. 목록 화면의 `<CR>`(미리보기)와 `gx`(브라우저)와 같은 규칙입니다.
- 본문은 평문 부분을 먼저 쓰고, 평문이 없으면 HTML 부분을 기존 변환기(pandoc)로 바꿔 씁니다. 한국 메일에 흔한 EUC-KR 같은 인코딩은 UTF-8로 바꿉니다.
- 읽음 처리는 하지 않습니다. nvim에서 읽어도 Gmail에서는 안 읽은 메일로 남습니다. 읽음 처리에는 더 넓은 권한이 필요해서 다음 단계로 미룹니다.
- 미리보기에서 `gx`는 Gmail을 브라우저로 엽니다. 헤드리스 Chrome 렌더링(`R`)은 메일에서 동작하지 않습니다. Gmail 페이지는 로그인이 필요하기 때문입니다.

### 범위

- 하는 것: 본문 가져오기, 평문·HTML 고르기, 인코딩 변환, 미리보기 표시, 첨부파일 이름 목록 표시, 가짜 `gws` 테스트입니다.
- 하지 않는 것: 첨부파일 내려받기, 인라인 이미지, 읽음 처리, 본문 캐시입니다.

### 남은 위험

- 복잡한 HTML 뉴스레터는 텍스트로 바꾸면 읽기 어렵습니다. 이런 메일은 `gx`로 브라우저에서 봐야 합니다.
- 미리보기 창은 RSS 목록과 함께 쓰는 창입니다. 메일을 띄운 상태에서 쓸 수 없는 키(`R`)는 아무 일도 하지 않습니다.
