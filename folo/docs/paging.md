# 자동 다음 페이지와 정렬 안내

상세: [paging.ai.md](paging.ai.md)

## 목적과 배경

지금은 `]p`를 눌러야 다음 페이지를 불러옵니다. 커서가 목록 끝에 가까워지면 다음 페이지를 저절로 불러오게 합니다. 도움말에는 한 번에 몇 개를 불러오는지와 어떤 순서로 정렬되는지를 적습니다.

## 결정 사항

- 커서가 목록 끝에서 정해진 줄 수(기본 5줄) 안으로 들어오면 다음 페이지를 불러옵니다. 0으로 두면 자동 로딩을 끕니다.
- `]p`는 그대로 둡니다.
- 페이지를 이어 붙일 때 이미 있는 글은 건너뜁니다. 다음 페이지의 기준점이 발행 시각 하나뿐이라 경계에서 같은 글이 다시 올 수 있기 때문입니다.
- 도움말에는 다음 내용을 적습니다. 한 번에 불러오는 개수(설정값, 없으면 CLI 기본 20개), 발행 시각 기준 최신순 정렬, 별표 목록도 별표를 누른 시각이 아니라 글 발행 시각 순서라는 점, 자동 로딩 조건입니다.

## 범위

- 하는 것: 자동 로딩, 중복 제거, 도움말 문구입니다.
- 하지 않는 것: 정렬 순서 변경, 무한히 쌓이는 목록의 메모리 제한입니다.

## 순서

1. 커서 이동 시 끝 근처인지 검사해 다음 페이지를 불러옵니다.
2. 이어 붙일 때 중복을 거릅니다.
3. 도움말 문구를 추가합니다.
4. 테스트를 추가합니다.

## 남은 위험

- 정렬 순서는 CLI가 기준점을 만드는 방식에서 추론했습니다. 서버 코드로 확인하지는 못했습니다.
- 발행 시각이 같은 글이 한 페이지보다 많으면 일부 글이 빠질 수 있습니다. 중복 제거로는 막을 수 없습니다.
