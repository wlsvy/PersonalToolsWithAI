# Folo AI 요약과 번역

상세: [ai.ai.md](ai.ai.md)

## 목적과 배경

크롬 확장의 [글 요약·번역](../../docs/features/summarize.md)을 Neovim 목록에서도 쓰려는 기능입니다. 여러 글을 골라 한꺼번에 요약하고, 더 읽을 글은 이어서 번역합니다.

## 결정 사항

- 사용자가 요청한 글만 처리합니다. 커서 이동이나 목록 열기만으로는 AI를 호출하지 않습니다.
- 요약과 번역은 큐에 넣고 정해진 개수만큼만 동시에 실행합니다. 구독 사용량과 요청 제한을 고려해 기본값은 3개입니다.
- 결과는 임시 버퍼가 아니라 Neovim 캐시 폴더의 파일로 저장합니다. 시간과 사용량이 드는 결과를 재시작 후에도 유지하기 위해서입니다. 저장소에는 들어가지 않고, 캐시를 지워도 다시 만들 수 있습니다.
- 결과는 목록에서 글 바로 아래의 자식 항목으로 표시합니다. 커서를 올리면 오른쪽 미리보기에 내용이 나옵니다.
- 번역은 요약 파일 아래에 덧붙입니다. 요약이 없는 글을 번역하면 요약부터 실행합니다.
- 프롬프트와 실행 방식은 크롬 확장과 같은 것을 씁니다. 도구를 모두 끄고 전용 프로필로 실행해, 웹 본문에 숨은 지시가 내 파일이나 설정에 닿지 않게 합니다.
- 원문을 읽지 못한 글은 요약하지 않습니다. 링크 한 줄만 보내면 AI가 내용을 지어낼 수 있기 때문입니다.

## 범위

- 하는 것: 단일 또는 다중 요약과 번역, 대기와 실행과 실패 표시, 실패 후 재시도, 결과 삭제입니다.
- 하지 않는 것: 진행 중인 작업 취소, 긴 글 분할 번역, 결과 검색, 크롬 확장과의 결과 공유입니다.

## 순서

1. 큐, 실행, 파일 저장을 담은 계층을 만듭니다.
2. 미리보기의 본문 가져오기를 요약 입력으로도 쓸 수 있게 나눕니다.
3. 목록에 자식 항목과 단축키를 추가합니다.
4. 가짜 Claude로 자동 점검을 하고, 실제 호출은 사용자가 확인합니다.

## 남은 위험

- 실제 호출은 구독 사용량을 씁니다. 11개 이상을 한 번에 요청하면 먼저 확인합니다.
- 전용 프로필에 로그인이 되어 있어야 합니다. 크롬 확장 설치 때 이미 했다면 다시 할 필요가 없습니다.
- 아주 긴 글은 번역이 끊기거나 시간 제한에 걸릴 수 있습니다.
- Neovim을 종료하면 진행 중인 작업은 중단되고, 완료되지 않은 결과는 저장되지 않습니다.

## 확장성 결정

사용자가 승인 없이 진행하도록 요청해 아래 기본값으로 진행합니다. 모두 설정으로 바꿀 수 있습니다.

1. 모델: 확장의 현재 호스트 구현과 같이 요약과 번역 모두 Sonnet을 씁니다.
2. 동시 실행 수: 3개입니다.
3. 실행 도구: Claude CLI만 지원합니다. 명령과 프로필 경로는 바꿀 수 있지만, 다른 AI 제공자를 위한 추상화는 만들지 않습니다.
