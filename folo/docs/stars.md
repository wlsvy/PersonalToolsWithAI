# 별표(컬렉션) 추가와 해제

상세: [stars.ai.md](stars.ai.md)

## 목적과 배경

목록에서 글에 별표를 붙이거나 뗍니다. Folo는 별표를 "컬렉션"이라 부르고, CLI에 추가·제거 명령이 있습니다.

## 결정 사항

- 키 하나로 별표를 켜고 끕니다. 기본 키는 `S`이며 설정에서 바꿀 수 있습니다.
- 선택한 글이 있으면 선택한 글 전체에, 없으면 현재 글에 적용합니다. 선택 중 하나라도 별표가 없으면 모두 붙이고, 모두 붙어 있으면 모두 뗍니다.
- 별표가 있는 글은 목록 줄에 ⭐를 표시합니다.
- 별표 목록에서 별표를 떼도 줄은 남기고 ⭐만 지웁니다. 실수했을 때 같은 키로 되돌릴 수 있습니다. 새로고침하면 빠집니다.
- 읽음 처리와 마찬가지로 CLI가 성공했을 때만 화면을 바꿉니다.

## 범위

- 하는 것: 목록에서의 별표 추가·해제, 별표 표시, 도움말 항목입니다.
- 하지 않는 것: 미리보기 창에서의 별표 키, 별표 목록을 별표 시각 순으로 정렬하는 것입니다.

## 순서

1. CLI 계층에 별표 추가·해제와 별표 여부 읽기를 넣습니다.
2. 목록 키와 ⭐ 표시를 넣습니다.
3. 가짜 CLI 테스트를 추가합니다.

## 남은 위험

- 일반 타임라인 응답에 별표 여부가 실제로 담겨 오는지 확인하지 못했습니다. SDK 타입에는 있습니다. 담겨 오지 않으면 타임라인에서는 ⭐가 보이지 않고, 키를 누르면 항상 "붙이기"로 동작합니다. 별표 목록에서는 모든 글을 별표 있음으로 봅니다.
- 이미 붙은 글에 다시 붙이거나 없는 글에서 떼면 서버가 어떻게 응답하는지 확인하지 못했습니다.
