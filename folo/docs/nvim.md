# Folo nvim 플러그인

상세: [nvim.ai.md](nvim.ai.md)

분할 화면과 미리보기는 [preview.md](preview.md), AI 요약과 번역은 [ai.md](ai.md), 작업 기록은 [progress.md](progress.md)에 있습니다.

## 목적과 배경

Neovim에서 Folo 타임라인을 읽고 읽음 상태를 관리합니다. 자체 서버와 Folo 사이의 글 ID를 맞추는 동기화는 어렵고 깨지기 쉽습니다. 그래서 Folo를 직접 조작하는 공식 CLI를 감싸 이 문제를 피합니다.

## 결정 사항

- 플러그인은 CLI만 실행하고 Folo API를 직접 호출하지 않습니다. 비공개 API 변경의 영향을 CLI가 대신 흡수하기 때문입니다.
- 플러그인은 토큰을 저장하거나 인자로 넘기지 않습니다. 로그인은 CLI에 맡깁니다.
- RSS 샘플과 코드를 공유하지 않고 독립된 디렉터리에 둡니다. 샘플을 언제든 지워도 영향이 없어야 하기 때문입니다.
- Folo 클라이언트 코드는 복사하지 않습니다. 라이선스가 AGPL이기 때문입니다.

## 범위

- 하는 것: 타임라인과 안 읽은 글 보기, 카테고리별 보기, 컬렉션 보기, 분할 화면 미리보기, 원문 가져오기, 다중 선택과 일괄 열기, 읽음과 안 읽음 전환, 다음 페이지, 원문 열기입니다.
- 카테고리 이름은 외울 필요가 없습니다. 계정의 구독 정보에서 목록을 가져와 고르게 합니다.
- 본문이 짧은 글은 원문을 자동으로 가져오되 피드 본문 아래에 덧붙입니다. 자세한 내용은 미리보기 문서에 있습니다.
- 하지 않는 것: 구독 관리, 컬렉션 추가와 제거, OPML, 검색, 전체 읽음 처리, 자체 RSS 서버와의 동기화입니다.

## 순서

1. 사용자 계정으로 CLI에 로그인하고 실제 출력 형식을 확인합니다.
2. CLI 실행과 오류 처리를 담은 계층을 만듭니다.
3. 타임라인, 본문, 읽음 처리 화면을 만듭니다.
4. 가짜 CLI로 자동 점검을 하고, 실제 계정으로 수동 점검을 합니다.

## 남은 위험

- CLI 버전이 아직 초기 단계라 출력 형식이 바뀔 수 있습니다. 확인한 공개 문서는 0.0.5 기준입니다.
- 샌드박스에서는 홈의 로그인 정보를 읽을 수 없어 실제 계정 점검을 사용자가 직접 실행해야 합니다.
- Folo 약관의 자동화 허용 여부는 아직 확인하지 않았습니다.

## 확장성 결정

사용자가 다음 권장안을 확정했습니다.

1. CLI 실행 방식은 전역 설치를 기본으로 하고 설정으로 바꿀 수 있게 합니다. 최신 버전 자동 실행은 쓰지 않습니다.
2. 계정은 하나만 지원합니다.
3. 화면 코드는 CLI 호출 계층만 사용하며, 여러 백엔드를 위한 추상화는 만들지 않습니다.
