# 대시보드

상세: [dashboard.ai.md](dashboard.ai.md)

## 목적과 배경

lazy.nvim처럼 첫 화면에서 상태를 한눈에 보고 원하는 목록으로 들어갑니다. 지금은 `:Folo`가 바로 전체 타임라인을 열어서, 어느 카테고리나 피드에 안 읽은 글이 쌓였는지 알 수 없습니다. CLI의 `unread list`가 피드별 안 읽은 개수와 카테고리를 돌려주므로 이것으로 화면을 만듭니다.

## 결정 사항

- `:Folo`는 대시보드를 엽니다. 전체 타임라인은 대시보드의 `t` 키로 엽니다. 나머지 명령(`:FoloUnread`, `:FoloCategory`, `:FoloStarred`)은 그대로 둡니다.
- 대시보드는 팝업이 아니라 새 탭에 엽니다. 탭 이름은 `Folo Dashboard`입니다. 탭이 이미 있으면 새로 만들지 않고 그 탭으로 이동한 뒤 새로고침합니다.
- 화면은 위에서부터 버튼 줄, 전체 안 읽은 개수, 카테고리별 피드 목록 순입니다. 카테고리와 피드는 안 읽은 개수가 많은 순으로 정렬합니다. 카테고리가 없는 피드는 `Uncategorized`로 묶습니다. 이 묶음은 CLI에 해당 필터가 없어 머리 줄에서 열 수 없고, 피드 줄은 열 수 있습니다.
- 버튼 줄과 개수는 배지로 표시합니다. 배지는 양 끝에 Nerd Font의 둥근 반원 글리프를 붙여 테두리처럼 보이게 하고, 테두리는 밝은 색, 안쪽은 같은 색을 어둡게 한 바탕으로 칠합니다.
- 카테고리 줄에서 `<CR>`을 누르면 그 카테고리의 안 읽은 글을, 피드 줄에서 누르면 그 피드의 안 읽은 글을 엽니다. 목록과 미리보기는 대시보드 탭 안에 열립니다. 목록에서 `q`를 누르면 대시보드로 돌아옵니다.
- 플러그인 설정의 `view`와 같은 view의 피드만 셉니다. 그래야 대시보드 숫자와 타임라인 내용이 맞습니다.

## 범위

- 하는 것: `:Folo` 대시보드 탭, 버튼 줄과 배지, 카테고리·피드별 안 읽은 개수, `<CR>`로 목록 열기, `r` 새로고침, `?` 도움말, 가짜 CLI 테스트입니다.
- 하지 않는 것: 피드 줄의 사이트 아이콘(`unread list`에 사이트 URL이 없습니다), 카테고리 접기·펼치기, 자동 새로고침, 대시보드에서의 읽음 처리입니다.

## 순서

1. CLI 계층에 `unread list` 읽기와 타임라인의 `--feed` 필터를 넣습니다.
2. 배지 그리기와 대시보드 탭, 키를 넣습니다.
3. `:Folo`를 대시보드로 바꾸고 README와 도움말을 고칩니다.
4. 가짜 CLI 테스트를 추가합니다.

## 남은 위험

- 탭 이름은 기본 tabline에서는 현재 창의 버퍼 이름을 따릅니다. 대시보드 탭에서 목록을 열면 탭 이름이 목록 이름으로 바뀝니다. 탭 변수 `tabname`도 함께 설정하지만 이를 읽는 tabline 플러그인에서만 고정됩니다.
- 반원 글리프는 Nerd Font가 없으면 깨집니다. 사이트 아이콘과 같은 조건이라 따로 대비하지 않습니다.
