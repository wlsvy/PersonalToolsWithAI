# 텍스트 치환 (Text Blaze 축소판)

웹 페이지 입력창에 정해둔 키워드를 입력하는 순간, 미리 정한 텍스트로 바뀐다.

예: `//copy` 입력 → `회의 메모 2026-11-01 <클립보드 내용>`

## 사용법

- 아무 웹 페이지의 입력창, 글상자, 편집기(Gmail, Notion 등)에서 키워드를 입력한다.
- 등록된 키워드

| 키워드 | 결과 |
|---|---|
| `//copy` | `회의 메모 <오늘 날짜> <클립보드 내용>` |
| `//date` | 오늘 날짜 (예: 2026-11-02) |

- 키워드를 추가·수정하려면 코드를 고치고 확장을 새로고침한다 (편집 화면 없음). 이미 열려 있던 탭도 새로고침해야 반영된다.
- 되돌리기(Ctrl+Z / ⌘Z)로 원래 입력으로 돌아갈 수 있다.

## Text Blaze와 비교

| Text Blaze | 이 기능 |
|---|---|
| 날짜/시간 넣기 | ✅ 날짜만 (YYYY-MM-DD 고정) |
| 클립보드 내용 넣기 | ✅ |
| 커서 위치 지정 | ❌ 결과 끝에 커서 |
| 입력 폼, 조건문, 수식 | ❌ |
| 스니펫 편집 화면 · 동기화 | ❌ 코드 수정 |
| 우클릭 메뉴 · 단축키 검색창 | ❌ |

## 한계

- 키워드가 입력되는 즉시 바뀐다. 한 키워드가 다른 키워드의 앞부분이면(`//c`와 `//copy`) 짧은 쪽만 동작하므로, 키워드끼리 앞부분이 겹치지 않게 정한다.
- 비밀번호 입력창에서는 동작하지 않는다 (의도적).
- iframe 안의 입력창, Google Docs에서는 동작하지 않는다.
- 편집기에서 키워드 중간에 서식(굵게 등)이 섞이면 인식하지 못할 수 있다.
- 입력 내용은 내 브라우저 안에서 키워드와 비교만 하고 어디에도 보내지 않는다.

## 나중에 할 것

| 원하게 되면 | 할 일 |
|---|---|
| 코드 수정 없이 스니펫 편집 | 편집 화면 + 저장 + `{date}` 같은 템플릿 문법 |
| 날짜 형식 바꾸기 | 날짜 함수에 형식 지정 추가 |
