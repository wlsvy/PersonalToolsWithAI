# 열린 탭 목록

popup을 열면 현재 창에 열린 탭들의 제목과 주소를 목록으로 보여준다.

## 사용법

- 툴바 아이콘을 눌러 popup을 열면 "열린 탭" 아래에 바로 보인다.
- 각 탭 오른쪽의 [요약] 버튼은 그 탭의 글을 요약한다 → [요약·번역](summarize.md)

## 동작

- 현재 창의 탭만 보여준다. 다른 창의 탭은 없다.
- 탭을 눌러 이동하거나 닫는 기능은 없다. 보기 전용이다.
- `chrome://` 같은 브라우저 내부 페이지는 [요약] 버튼이 비활성화된다.

## 나중에 할 것

| 원하게 되면 | 할 일 |
|---|---|
| 목록에서 눌러 이동·닫기 | 탭 이동/닫기 연결 |
| 모든 창의 탭 보기 | 창별로 묶어서 표시 |
