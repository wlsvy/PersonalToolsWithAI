# 흑백 필터

현재 보고 있는 탭을 흑백으로 바꾸고, 한 번 더 누르면 원래대로 돌린다.

## 사용법

- popup의 [흑백 전환] 버튼, 또는 페이지 우클릭 → "흑백 전환"

## 동작

- 켠 상태는 저장하지 않는다. 페이지를 이동하거나 새로고침하면 원래 색으로 돌아온다.
- 지금 탭에만 적용된다. 다른 탭은 그대로다.

## 한계

- `chrome://` 페이지와 Chrome 웹 스토어에서는 동작하지 않는다 (Chrome 정책).
- 일부 사이트에서 화면에 고정된 요소(상단 바 등)의 위치가 틀어질 수 있다.

## 나중에 할 것

| 원하게 되면 | 할 일 |
|---|---|
| 새로고침·새 탭에도 흑백 유지 | 켠 상태를 저장하고 페이지가 열릴 때마다 다시 적용 |
