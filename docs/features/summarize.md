# 글 요약·번역

읽던 글을 먼저 **요약**해서 보여주고, 더 읽을 글이면 **전문을 한국어로 번역**해 같은 탭에 보여준다. 파일로 저장하지는 않는다.

## 사용법

1. 시작
   - 페이지 우클릭 → "요약·번역 (새 탭)", 또는
   - popup의 열린 탭 목록에서 원하는 탭의 [요약] 버튼
   - 사이드 패널로 보려면 우클릭 → "요약·번역 (사이드 패널)" 또는 popup의 [사이드 패널에 요약] 버튼을 누릅니다. 현재 탭 옆에 같은 결과 화면이 열립니다.
2. 새 탭에 요약이 뜬다 (보통 수십 초).
3. 읽고 판단한다.
   - **[요약 Markdown 복사]**: 요약 원문(Markdown)을 클립보드에 복사한다.
   - **[마저 번역]**: 전문을 번역해 아래 "번역" 칸에 보여준다. 긴 글은 몇 분 걸린다.
   - 필요 없으면 탭을 닫는다.

결과 탭은 원래 페이지가 없어도 동작한다. 요약이 뜨는 동안 원래 탭을 닫거나 다른 페이지로 가도 된다.

## 결과 화면

- 맨 위에 제목, 원문 주소, 단어 수(WordCount)
- 요약은 '눈여겨볼 점' 불릿과 섹션 제목 앞에 이모지를 붙여 훑어보기 쉽게 만듭니다. 이 규칙은 `native-host/prompts/summary.md`에 있고 Folo nvim 플러그인도 같은 프롬프트를 씁니다.
- 요약·번역은 서식(제목, 목록, 표, 이미지)과 다이어그램(mermaid)까지 보기 좋게 표시
- 맨 아래 "원문 Markdown"을 펼치면 추출한 원문을 그대로 볼 수 있다

## 비용과 모델

내 Claude 구독으로 돌아간다 (API 키 불필요). Opus 대신 저렴한 모델을 쓴다.

| 단계 | 모델 | 이유 |
|---|---|---|
| 요약 | Haiku | 더 읽을지 판단용. 자주 돌고 품질 요구가 낮다 |
| 번역 | Sonnet | 누른 글만. 전문 용어 번역 품질이 필요하다 |

요약을 먼저 보고 판단하는 이유는 버릴 글까지 번역하지 않기 위해서다.

## 설치 (최초 1회)

1. `chrome://extensions`에서 확장을 새로고침하고 확장 ID를 복사
2. 터미널에서 호스트 등록 스크립트 실행
   - macOS: `./native-host/install.sh <확장 ID>`
   - Windows (PowerShell): `.\native-host\install.ps1 <확장 ID>` (확장 ID 생략 시 `mytools/` 경로로 자동 계산)
3. `claude`에 로그인되어 있지 않으면 한 번 실행해 `/login`

결과 탭에 "Not logged in"이 뜨면 3번을, "host not found"가 뜨면 2번을 다시 한다. `mytools/` 폴더를 옮기면 확장 ID가 바뀌므로 2번을 다시 한다.

## 한계

- 요약 형식과 번역 품질은 모델에 따라 달라질 수 있다.
- 아주 긴 글은 번역이 중간에 끊길 수 있다 (아직 확인 안 됨).
- 브라우저를 껐다 켜면 열려 있던 결과 탭의 내용은 사라진다. 원래 페이지에서 다시 실행한다.
- 사이드 패널은 그 탭에만 붙습니다. 다른 탭으로 가면 숨겨지고, 돌아오면 다시 보입니다.
- 본문 추출 한계는 [본문 Markdown 복사](clip-markdown.md)와 같다.
