# 클립보드 기록

최근에 복사한 텍스트를 최대 5개까지 기억합니다. popup에서 예전 항목을 골라 다시 복사할 수 있습니다.

## 사용법

- popup을 열면 "클립보드 기록"에 최신순으로 5개가 보입니다.
- 항목 옆 [복사]를 누르면 그 텍스트가 다시 클립보드에 들어가고, 목록 맨 위로 올라갑니다.
- 마우스를 올리면 앞부분 500자를 미리 볼 수 있습니다.

## 무엇이 기록되는지

- 웹 페이지에서 Cmd+C / Cmd+X로 복사·잘라내기한 텍스트가 기록됩니다.
- 이 확장으로 복사한 내용(본문 Markdown 복사·이어 붙이기, 요약 결과 복사)도 기록됩니다.
- 다른 앱(터미널, 메모 등)에서 복사한 내용은 **popup을 여는 순간** 클립보드에 있는 것만 기록됩니다.
- 같은 텍스트는 중복되지 않고 맨 위로 올라갑니다. 이어 붙이기로 늘어난 결과는 이전 항목을 대체합니다.

## 한계

- 브라우저를 닫으면 기록이 지워집니다. 복사한 비밀번호 등이 디스크에 남지 않도록 일부러 메모리에만 둡니다.
- 페이지의 "복사" 버튼(GitHub 코드 복사 등)은 대부분 기록되지 않습니다. 다만 popup을 열면 그때 클립보드에 있는 내용으로 기록됩니다.
- 비밀번호 입력창에서는 기록하지 않습니다. 다만 비밀번호 관리자가 클립보드에 넣은 비밀번호는 popup을 열 때 기록될 수 있습니다(브라우저를 닫으면 지워집니다).
- 텍스트만 기록하며 이미지는 기록하지 않습니다.
- 확장을 새로고침하면 열려 있던 탭은 새로고침해야 다시 기록됩니다.
