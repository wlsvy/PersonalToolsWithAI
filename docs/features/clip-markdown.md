# 본문 Markdown 복사

지금 보고 있는 페이지에서 광고·메뉴를 빼고 **본문만** Markdown으로 바꿔 클립보드에 복사한다. LLM에 붙여넣거나 메모로 옮길 때 쓴다.

## 사용법

- popup의 [본문 Markdown 복사] 버튼 → 복사된 글자 수가 표시된다.
- 또는 페이지 우클릭 → "본문 Markdown 복사"

## 동작

- 맨 위에 글 제목이 `# 제목`으로 붙는다.
- 이미지는 Markdown 이미지 링크로 남는다 (파일을 내려받지는 않는다).
- 본문을 찾지 못하면 복사하지 않는다. 기존 클립보드 내용은 그대로 남는다.
- 네이버 블로그처럼 본문이 페이지 안의 별도 영역(iframe)에 있는 경우도 찾는다.

## 한계

- 본문 판단은 자동이라 사이트에 따라 일부가 빠지거나 불필요한 부분이 섞일 수 있다.
- `chrome://` 페이지, 웹 스토어, Chrome의 PDF 뷰어에서는 동작하지 않는다.
- 우클릭 메뉴로 실행했다가 실패하면 따로 알림이 없다 (popup에서는 안내가 뜬다).
